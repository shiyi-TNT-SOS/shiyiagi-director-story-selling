# 生产层：一致性 · 衔接 · 抽卡成本 · 引擎矩阵 · 声音

> 前面几份文件教的是「怎么写提示词」。本文件管另外四件事：
> **多镜怎么保持一致、镜头怎么接得起来、钱怎么花、声音怎么设计。**
> 写提示词可能 20 分钟，抽卡返工是几小时——这份文件针对那几小时。

## 零、端到端生产流程（先看这张图）

```
① brief ──► ② 骨架/人设 ──► ③ 分镜表 ──► ④ 逐镜 prompt
                                              │
                                              ▼
                          ⑨ 发布 ◄── ⑧ 声音 ◄── ⑦ 剪接 ◄── ⑥ 挑选 ◄── ⑤ 生成(抽卡)
                                                                          │
                                                                          └─► 不满意 → 回到 ④ 改 prompt（锁变量）
```

| 步 | 输入 | 输出 | 检查点 | 卡住了查 |
|---|---|---|---|---|
| ① 收 brief | 用户一句话需求 | 6 项信息（缺项标假设） | 假设项是否已明确标出 | SKILL.md 第 1 步 |
| ② 定骨架/人设 | brief | 转化骨架 / 戏剧功能 / 四拍 / 导演人设 | 骨架是否填实 | 各技能主 reference |
| ③ 分镜表 | 骨架 | 表格 + 表格后三块 | 每镜是否挂靠到骨架的一项 | 各技能主 reference |
| ④ 逐镜 prompt | 分镜表每一行 | 一条可粘贴 prompt | 顺序是否「主体动作」开头 | `ai-video-prompt.md` |
| ⑤ 生成（抽卡） | prompt + 参考图 | 一镜多条候选 | 是否一次只改一个变量 | **本文件 三** |
| ⑥ 挑选 | 候选片 | 能用 / 能修 / 废 三类 | 是否有归档标准 | **本文件 三.3.7** |
| ⑦ 剪接 | 能用+能修的镜 | 成片 | 轴线是否跳、切点是否在动作完成前 | **本文件 二** |
| ⑧ 声音 | 成片 | 带声成片 | 静默节点是否用上 | **本文件 五** |
| ⑨ 发布 | 成片 | 上线 | 平台规格与合规 | `platform-specs.md` `compliance.md` |

**三条最容易被跳过的：**⑥ 挑选归档、⑦ 轴线检查、⑧ 静默节点。跳过这三步的片子，观众说不出哪里不对，但就是"业余"。

## 一、一致性：多镜叙事的生死线

### 1.1 三级一致性武器（按可靠性排序，按需选贵的）

| 手段 | 一致性上限 | 成本 | 适用场景 |
|---|---|---|---|
| 纯文字描述串 | **低** | 零 | 单镜、远景、背影、非关键角色、空镜 |
| 参考图（角色定妆图 / 产品实拍图） | **中高** | 需先出定妆图 | 有正脸的中近景、跨镜出现的主角、产品特写 |
| 首尾帧接力（上一镜末帧 → 下一镜首帧） | **最高（限同场景内）** | 逐镜串行，不能并行 | 连续剧情、对白戏、同场景多镜 |
| 参考图 + 首尾帧 双锁 | **最高** | 最高 | 换场景/换装但仍需同一张脸 |

> 关键认知：**文字描述的一致性上限很低**——同一段描述，模型每次理解都略有不同，第 5 镜的人已经不是第 1 镜的人。想要真正锁住，必须上参考图。

### 1.2 角色卡（Character Card）模板

一次写好，全片复用。**不写角色卡 = 每镜重新描述 = 必然漂移。**

```
【角色名】林小满

- 年龄与身份：26 岁，咖啡师
- 脸型与五官：鹅蛋脸；圆眼、单眼皮、眼角微下垂；鼻梁低、鼻头圆；唇薄、嘴角平
- 发型：黑色齐肩直发，中分，右侧别一枚黑色一字夹
- 肤色与体态：偏暖黄皮；肩窄、身形偏薄，身高约 165
- 服装：米白棉麻衬衫（袖口挽两折）+ 深灰直筒长裤 + 白帆布鞋
- 随身物件：左腕一只旧银色细表
- 一句话气质：安静、有点疲惫、不轻易示弱
- 此刻状态：强撑着不想让人看出累（逐场戏可改）
```

**可复用描述串**（从角色卡压出来，直接粘进每条 prompt 的「主体」段，一字不改）：

```
26岁亚洲女性，鹅蛋脸，单眼皮圆眼，黑色齐肩直发中分右侧一字夹，暖黄皮，
米白棉麻衬衫深灰长裤，左腕银色细表，肩窄身形偏薄
```

> 用法铁律：**这段串在每条 prompt 里必须逐字相同**。手改一个词（"黑色"改成"乌黑"），一致性就断一次。

若角色多于 2 人，各建一张卡；同屏出现时，两条描述串都要进 prompt。

### 1.3 角色定妆图（多角度参考图生成法）

真正锁住脸的做法不是描述，是**资产**：

1. 用图片模型生成角色正面半身定妆图：干净背景、中性光、无表情、正脸 → 抽 6–10 张挑 1 张
2. 以这张为首帧或参考，生成 **3/4 侧、正侧、背面** → 得到 4 张一套"角色资产"
3. 全片每次生成都挂这套参考图（不是挂一张）
4. 需要换装：用图片模型的**局部重绘**只改服装区域，脸保持不动 → 得到"同一人不同服装"的资产

> 情绪表情同理：需要"哭""怒""笑"时，从定妆图派生表情图，而不是靠 prompt 描述情绪让模型现编。

### 1.4 首尾帧接力的实操细节（这里有坑）

- **别接运动模糊的末帧。** 末帧如果有拖影/暗部噪点，会污染下一镜的首帧。选运动停在清晰处的那一帧。
- **接力链别超过 4–5 跳。** 误差逐跳累积，第 4 跳之后人物开始慢慢变样。做法：**每 3 跳用角色参考图"回锁"一次**。
- **跨场景不要接力。** 场景变了，上一镜末帧带的是旧场景，会把旧场景"传染"进新场景。跨场景改用参考图锁人，不锁帧。
- **首尾帧与参考视频互斥。** 部分引擎（如 Seedance 2.5 的官方说明）在设置了首尾帧后，会忽略参考视频与参考音频——别指望同时用。
- **首尾帧 ≠ 锁构图。** 它锁的是首尾两帧，中间怎么走模型仍自由发挥。要看中间过程还得靠 prompt 描述。

不在这里重复，见 `troubleshooting.md`：一、人物类。

## 二、镜头衔接与转场：分镜表 → 成片之间断掉的一环

**每镜都好看，拼起来晕** —— 症状几乎总是这两个：跳轴，或者切点踩错。

### 2.1 180° 轴线（最重要，也最容易忽略）

**轴线 = 主体之间的那条假想连线。** 机位必须待在连线同一侧，跨过去就是"跳轴"，观众会瞬间失去空间感。

AI 生成片的特殊难点：**每次生成等于重新布置一次现场**，你不知道模型把人物放在画面哪一边。所以不能靠"拍的时候注意"，必须**写进 prompt 和分镜表**。

实操：

- 分镜表加一列「**方位/朝向**」，开拍前就定死：
  ```
  镜1  A 在画面左、B 在画面右   A 面朝右
  镜2  同上                    A 面朝右（过肩）
  镜3  同上                    A 面朝右（B 越肩）
  ```
- 每条 prompt 的「主体动作」段带上朝向词：「面向画面右侧」「背对镜头偏左」「视线朝画面左下」
- **越轴的两个合法手段**（真想换边时）：
  1. 中间插一个**中性镜**（正面 / 背影 / 空镜）再换边——观众被"重置"了方位
  2. 让**镜头在画面内运动过轴**（一个越肩摇过去），让观众亲眼看见位置变化
- 单人镜没有轴线，但有**视线方向一致**：前一镜看左，后一镜不能看右，除非有转头镜过渡。

### 2.2 匹配剪辑（match cut）

用一个"形状/动作/声音"把两个镜缝在一起，让切换不刺眼：

| 类型 | 原理 | 可执行写法 |
|---|---|---|
| 形状匹配 | 前后镜有相似的几何形 | 前镜圆形杯口 → 后镜圆形钟面；prompt 里把形状写进构图 |
| 动作匹配 | 前镜动作未完成就切 | 前镜抬手（未落下）→ 后镜手已落（另一场景）；两镜都写"抬手动作" |
| 声音匹配 | 前镜的声音延续到后镜 | 前镜"水声起" → 后镜"水声继续但场景已换" |

动作匹配最能掩盖 AI 生成的不一致——观众注意力在"动作完成"上，会自己补完中间。

### 2.3 转场五件套（按对 AI 生成片的友好度排序）

| 转场 | 怎么做 | 什么时候用 | AI 友好度 |
|---|---|---|---|
| **硬切** | 直接切 | 默认，90% 的场合 | 最安全 |
| **遮挡转场** | 前景物体（人走过、车门关、手扫过）遮住画面瞬间切 | 换场景、换时间 | ⭐ 最友好——遮挡帧天然掩盖不一致 |
| **动作匹配切** | 见 2.2 | 跨场景但动作连贯 | ⭐ 很友好 |
| **甩镜转场** | 镜头快速横甩，中段模糊时切 | 节奏紧凑的动作/带货 | 友好——模糊掩盖接缝 |
| **跳切** | 同机位同景别连续切 | 表现焦躁、时间流逝、压缩过程 | 友好（不需要生成新素材） |
| 叠化 / 闪白 | — | 时间跨度大、回忆、结尾 | **后期做**，不要指望生成 |

> 一条实用经验：**需要接缝的地方，优先用「遮挡转场」**——让一个前景物体扫过画面。这是 AI 生成片里最省事、最不容易露馅的转场。

### 2.4 切点选择（"利落"和"拖沓"的分界线）

- **在动作完成前切**，不要等动作做完再切。观众会自己补完剩余动作——这是"节奏"的本质。
- **台词切点给听者。** 在说话人身上切是业余；切到听者的反应上是专业。
- **情绪高点不要切。** 让镜头停住 2 秒，情绪才落地。高点一闪而过 = 白拍。
- **不要在静帧上切。** 切点选在主体有微小运动的那一帧，切换更顺。

### 2.5 分镜表加一列「转场」

建议在各技能的分镜表输出契约里补上「转场/衔接」列，写清"本镜怎么进、怎么出"。哪怕全写"硬切"也比不写强——它逼你检查一遍衔接。

## 三、抽卡与成本策略

这一节直接决定烧多少钱。

### 3.1 一镜出几条（先算总数，再算钱）

| 镜头类型 | 一次出几条 | 说明 |
|---|---|---|
| 关键镜（正脸 / 台词 / 产品特写 / 首镜） | **4–8 条** | 值得抽 |
| 普通镜 | 2–3 条 | |
| 空镜 / 氛围镜 | 1–2 条 | 废片率低 |

**先算总数再开抽**：镜数 × 条数 × 单价 = 预算。边抽边加是最常见的超支方式。

### 3.2 迭代顺序：一次只改一个变量 ⭐

**最烧钱的行为：** 这次同时改光线 + 改运镜 + 改景别 → 出了好片不知道好在哪，出了废片不知道哪错了。

正确顺序（**改到哪一步满意就停**，不要往下改）：

```
① 构图对不对   ← 景别 / 角度 / 主体位置 / 朝向
② 主体动作对不对 ← 谁做了什么、重心怎么移
③ 运镜有没有执行 ← 只验一个运镜
④ 光线与色彩   ← 方向 / 硬度 / 色温 / 主色
⑤ 细节质感     ← 皮肤 / 材质 / 碎屑 / 布料
```

每动一层，**其他层原封不动复制**。第 ① 层没定就改第 ⑤ 层，等于白花钱。

### 3.3 迭代降本三板斧

1. **低分辨率试构图**：480p / 720p 试 5 秒，构图对了再上 1080p / 30s。成本差 3–8 倍。
2. **短时长试动作**：先用 5 秒验证动作，满意了再用「延长/续接」拉到目标时长，而不是一上来就抽 30 秒。
3. **运镜参考视频复用**：同一段运镜要在多镜复用，就备一条参考视频反复挂，省的是重抽次数。

### 3.4 哪些镜**必须**图生视频（不能纯文生）

- 有主角正脸的中近景与特写
- 产品特写（带货）
- 连续剧情的第 2 镜及之后
- 需要精确落首尾帧的镜
- 需要复刻某个运镜/风格的镜（用参考视频）

### 3.5 哪些镜**可以砍**（省钱不伤片）

- **纯过渡空镜** → 用上一镜的尾帧定格 0.5s 代替
- **重复信息镜** → 两镜在说同一件事，删一个
- **无功能镜** → 故事片没挂戏剧功能、带货不承担转化段落、广告没承担卖点
- **纯炫技运镜镜** → 运镜很好看但不推进任何事

### 3.6 废片率预估（按这个留预算）

| 内容 | 废片率 | 预算倍数 |
|---|---|---|
| 手部精细动作 / 多人同框 / 快速运动 / 需要文字 | **50%+** | ×2 |
| 单人 + 固定机位 / 空镜 / 静态产品 | 10–20% | ×1.2 |
| 首尾帧接力链 | 逐跳上升，第 4 跳后明显恶化 | 前 3 跳 ×1.2，之后 ×2 |

### 3.7 挑选归档（第 ⑥ 步，最容易被跳过）

候选片按三类归档，**边看边归，不要看完再回忆**：

| 类别 | 标准 | 处理 |
|---|---|---|
| **能用** | 无崩坏，可直接进剪 | 标记镜号 + 版本号 |
| **能修** | 主体可用，但光线/色彩/长度不对 | 记下"只改哪一层"，进下一轮迭代 |
| **废** | 人物崩 / 动作崩 / 构图错 | 记下崩点，对应查 `troubleshooting.md` |

> 归档的意义：**避免为同一个问题重抽两次**。不归档就会反复抽同一个坑。

### 3.8 预算公式

```
总预算 ≈ Σ(每镜单价 × 条数) × 废片系数(1.2–2.0) + 重抽预留(30%)
```

## 四、引擎能力矩阵

### 4.0 先分清：入口 ≠ 模型

选型时最容易搞错的一层：

| 入口（你在哪点按钮） | 底层模型 | 归属 |
|---|---|---|
| 即梦 Dreamina / 豆包 | **Seedance 系列** | 字节 |
| 可灵 AI | **Kling 系列** | 快手 |
| Grok Imagine | Grok Video | xAI |

**你选的从来不是"即梦还是可灵"，是"Seedance 还是 Kling"。** 入口只是包装。这决定了"哪个更好"这类问题要先问"你用的是哪一代模型"。

### 4.1 能力矩阵（快照日期 2026-10）

| 维度 | Seedance 2.5 | Seedance 2.0 | Kling 2.6 |
|---|---|---|---|
| 单次生成时长 | **4–30s** | 4–15s | 5s / 10s |
| 分辨率 | 480p / 720p / 1080p | 主流 720p–1080p | 1080p（Pro）/ 更低（Standard） |
| 画幅 | 6 档：21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16 | 常用 16:9 / 9:16 | 3 档：16:9 / 9:16 / 1:1 |
| 原生音频 | ✅ 画面+对白+音效+音乐同趟生成，口型对齐 10+ 语言 | ✅ 同趟生成 | ✅ 同趟生成（对白/歌唱/音效/环境），中英双语 |
| 首尾帧 | ✅（1 图 = 首帧，2 图 = 首尾帧） | ✅ | ✅（start / end frame 插值） |
| 参考图 | 官方文档口径最多 30 图（与 10 视频 + 10 音频合计 50 路多模态） | 约 9–12 图 | 最多 4 图（Elements） |
| 参考视频（运动迁移） | ✅ 2–30s 参考视频 | 部分支持 | ✅ **Motion Control，当前最可靠** |
| 局部编辑 | ✅ 区域级改（换产品 / 换服装 / 改背景） | ❌ | 有限（motion brush / 遮罩） |
| 前后延长 | ✅ 可向前/向后接长（超长档为 beta） | ❌ | 用首尾帧接力代替 |
| 一条 prompt 多镜 | ✅ 可写 Shot 1 / 2 / 3 时间轴 | 部分 | 有限（有 multi-shot 选项） |
| 精确落首尾帧 | 一般 | 一般 | **最强**（更新的 Kling 3 代以首尾帧落点为核心规格） |
| 水印 | 输出无水印 | 输出无水印 | 默认加水印，可选项同时产出无版本 |
| 独立负面词字段 | 视渠道 | 视渠道 | ✅ 有 `negativePrompt` 字段 |
| 上手门槛 | 中（模式靠附件**自动判断**，没有模式按钮） | 低 | 低（参数化程度最高） |

### 4.2 一个高频踩坑：Seedance 2.5 没有"模式选择"按钮

**放什么附件决定走什么模式，提示词用什么动词决定走生成还是编辑：**

| 你手里有什么 | 会走的模式 | 触发条件 |
|---|---|---|
| 只有一句描述 | 文生视频 | 不放附件 |
| 1 张图 | 图生视频 | 图成为首帧 |
| 起始图 + 结束图 | 首尾帧 | 放 2 张图，按顺序 |
| 3 张以上风格/主体参考 | 参考组 | 放 3 张以上图 |
| 一段视频要改 | 视频编辑 | 放视频 + 提示词用「去掉 / 替换 / 改成 / 剪掉」 |
| 一段视频要接长 | 视频延长 | 放视频 + 提示词用「延长 / 续拍 / 接着拍」 |

> 症状：**"我想改视频，结果它给我重新生成了一条"** → 不是模型坏了，是动词没写对。
> 另注：视频编辑模式常按较长额度预扣计费，是最容易算错的一项。

### 4.3 负面词：两种引擎两种写法 ⚠️

全系列铁律是「不写否定句」（negation summons），但要**分清字段**：

- **有独立负面词字段的引擎**（如可灵 `negativePrompt`）：把排除项写进**字段**，不要写进正文
  → `watermark, slow motion, deformed hands, extra fingers`
- **没有独立字段的引擎**：排除项写在提示词**末尾**（模型对句尾否定的响应较好）
- **文字类排除，任何引擎都不要写**（`no text` / `无字幕`）：文字类否定在正文和负面词表里**都有被召唤的风险**，而收益极低——字幕一律后期叠加
- 一句话总结：**实物排除进字段或句尾，文字排除走构图 + 后期**

### 4.4 选引擎决策树

```
需要 >15s 单镜一次成？          → Seedance 2.5
需要精确落首尾帧（严丝合缝）？   → Kling（3 代最强）
需要运动迁移（复刻某段运镜）？   → Kling Motion Control 或 Seedance 参考视频
需要换产品/换服装而不重抽？      → Seedance 2.5 局部编辑
要省钱试构图？                  → 低分辨率档，或更便宜的老一代模型
要最省心的中文消费级上手？       → 即梦（Seedance 入口）
需要多人对白不同声音？           → Kling（最多 2 个声音 ID）
```

### 4.5 这份快照会过期

参数随版本更新。快照日期 **2026-10**。定价与档位以各引擎**当前官方文档**为准；发现对不上，**改这张表，不要改主模板**。

## 五、声音设计（别只写"音效"两个字）

### 5.1 三层优先级（全系列一致）

**音效 > 环境音 > 台词 > 不用背景配乐**

理由：原生音频里的配乐最容易盖住口型与音效，而且用户自己的 BGM 通常更好。**"无背景音乐"是一个主动的创作选择，不是省略。**

### 5.2 音效清单模板（逐镜填，不要留空）

| 镜 | 主体音效（画面内动作发出） | 环境音（场景底色） | 静默节点 |
|---|---|---|---|
| 1 | 布料摩擦、脚步踩碎叶 | 远处车流、风过树 | 无 |
| 2 | 水倒入杯中的注水声 | 冰箱低频嗡鸣 | 台词前 0.3s 抽掉环境音 |

主体音效与环境音是两回事：主体音效**跟动作走**，环境音**整场不变**。只写前者，画面会"干"。

### 5.3 拟音（foley）思路

不要写抽象的"紧张的音效"，写**什么物件发出什么声音**：

- ❌ "紧张刺激的音效"
- ✅ "金属钥匙串在掌心收紧的碰撞声"
- ❌ "轻快的背景音"
- ✅ "勺子碰到瓷杯壁的清脆声 + 咖啡馆人声底噪"

### 5.4 静默的用法（最被浪费的音效）

1. **台词前静默**：0.3–0.5s 抽掉环境音，台词立刻被听见
2. **冲击前静默**：打击发生前一瞬静音，冲击感翻倍（动作片标配）
3. **结尾静默**：情绪落点处只留环境音，比配乐更高级

### 5.5 台词时长换算

中文口语约 **2.5 字/秒**。10 字台词 ≈ 4 秒，前后各留半拍呼吸。写台词时先算秒数，再决定镜长——反过来必然超时。

## 六、带货专属生产要点

### 6.1 产品一致性是带货的生死线

**产品不像 = 整条视频作废**，而且是那种"发出去才发现、已经跑了流量"的作废。三条铁律：

1. **实拍图优先**：有产品实拍图就必须用**图生视频 / 参考图**。纯文字描述的上限很低，瓶身比例、标识、字体基本靠猜。
2. **外观锁定串**（与 `ai-video-prompt.md` 的四项对齐，每条 prompt 逐字复用）：
   ```
   品类与形态 + 主色与材质 + 显著特征 + 与人物/画面的尺度关系
   ```
3. **一镜一个产品**：多 SKU 不同框。换产品就换参考图，不要指望 prompt 里改描述能切干净。

### 6.2 结果对比镜的生成规范

前后对比是带货的核心说服点，也是 AI 最容易露馅的地方：

- **同机位、同景别、同光线、同构图** —— 只改主体状态。机位一变，观众立刻怀疑是两条无关素材，「对比」的说服力直接归零。
- **推荐做法**：先生成"使用后"这一镜、把机位定死，再用**同一条 prompt** 生成"使用前"（只改主体状态描述）。比分别设计两镜可控得多。
- **不要用 AI 直接生成"变好"的功效画面**——涉及功效真实性与合规红线，见 `compliance.md`。画面只呈现"使用过程"，功效表述交给台词与文案且不得超备案范围。

### 6.3 手部动作的降级方案（带货的最高频崩点）

带货偏偏大量拍手部使用动作，而手部畸变是当前模型最高频的失败点。按**风险从低到高**选用：

| 优先级 | 方案 | 说明 |
|---|---|---|
| 1 | 产品放桌面，手从画面外入画 | 只需手腕，完全避开手指 |
| 2 | 手部局部大特写 | 只拍 1–2 根手指 + 产品局部 |
| 3 | 让产品遮挡手部 | 手掌藏在瓶身/盒体后面的位置 |
| 4 | 换使用方式 | 「喷 / 挤」（单手拇指动作）比「拧 / 掰」（多指精细）稳得多 |

> 这四条与 `ai-video-prompt.md` 的"避开复杂手部动作"表一致，此处的价值是**给出了优先级排序**，抽卡前照着降级。

### 6.4 人物数量的硬限

全片人物 **≤ 2 人**（沿用 SKILL.md【边界】的约束）。超过 2 人时：

- 群像改**单人特写 + 局部**（手 / 背影 / 肩部）穿插
- 需要"很多人都在用"的语义 → 用 3–4 个**单人镜快切**，而不是一镜多人
- 需要对话时，用**过肩镜头遮挡一方**，画面里只出现一个人

### 6.5 挂车、评论区与审核（生成之外的三件事）

这三件决定了视频能不能变现：

| 事项 | 做法 |
|---|---|
| **挂车时机** | CTA 段画面回到人物时可挂；**不要在产品特写上挂**（显得急） |
| **评论区首条预埋** | 分镜表输出契约已要求给"评论区首条质疑 + 应对话术"，发布后**立即自评置顶** |
| **审核风险点** | 痛点段不得丑化目标人群；结果对比不得伪造；功效不得超备案范围。详见 `compliance.md` |

### 6.6 带货预算分配建议

| 位置 | 占比 | 理由 |
|---|---|---|
| 钩子（0–3s） | **50%** | 决定有没有人往下看，值得抽最多的条数 |
| 产品登场 + 使用过程 | **30%** | 产品一致性的钱在这 |
| 结果对比 | **20%** | |

> 中间两段（痛点放大、转折）可以用**最省的镜**：小景别、固定机位、单人、屏内道具少。这两段的功能是"叙事"，不是"质感"。

### 6.7 带货专属排错

产品不像 / 手部崩坏 / 人物超 2 人 / 结果对比两张对不上 / 口型不对，见 `troubleshooting.md`：七、带货专属崩坏。
