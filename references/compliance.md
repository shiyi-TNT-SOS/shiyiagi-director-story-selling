# 带货合规红线

> **重要**：本文为常见高风险表述的速查清单，用于起草阶段自查。
> 《广告法》条款与平台规则会更新，且各平台（抖音/快手/小红书/视频号）执行口径不同。
> **发布前必须过一遍投放平台后台的违禁词检测，并以平台最新规则为最终依据。**

---

## 一、绝对化用语（最高频违规）

| 禁用 | 安全替代 |
|---|---|
| 最好、最佳、最优 | 我用下来最顺手的 / 复购最多的一款 |
| 第一、No.1、全网第一 | 具体名次 + 数据来源 + 时间范围 |
| 顶级、极品、天花板 | 具体到参数或体验描述 |
| 全网最低、史上最低 | 删除，或写明比价时间与范围 |
| 唯一、独家、绝无仅有 | 具体到"某时间段内某渠道" |
| 秒杀一切、吊打 | 删除（同时涉嫌贬低竞品） |

---

## 二、效果承诺（剧情带货重灾区）

| 禁用 | 安全替代 |
|---|---|
| 根治、彻底解决、一次搞定 | 缓解 / 改善 / 明显减轻 |
| 100% 有效、绝对有效、包好 | 具体场景下的具体效果 |
| 永久、终身不再、永不反弹 | 长期使用的维持效果 |
| 三天见效、七天美白 | 使用过程中的变化描述 |
| 无副作用、零风险、绝对安全 | 删除（任何产品都不能这样表述） |

**剧情带货的特殊风险**：为了制造转折和结果对比，很容易写出"用之前怎样、用之后彻底好了"的结构。这种前后对比天然接近效果承诺，**必须用画面差异代替功效断言**——展示"油污没了"，不要说"强力去污无残留"。

---

## 三、医疗与功效暗示（普通商品禁用）

| 禁用 | 说明 |
|---|---|
| 消炎、杀菌、抗菌、抑菌 | 属医疗/消毒用语，需对应资质 |
| 治疗、疗效、治愈、修复 | 同上 |
| 修复受损、再生、激活细胞 | 化妆品备案范围外的功效宣称 |
| 美白、祛斑、防晒 SPF 值 | 属特殊化妆品，需特证备案 |
| 减肥、燃脂、排毒、刮油 | 保健食品需蓝帽子，普通食品禁用 |
| 降压、降糖、降血脂 | 属药品功效，绝对禁用 |
| 缓解颈椎病、治疗失眠 | 属疾病治疗宣称 |

**判断原则**：不是"能不能说"，而是"有没有对应的资质与备案"。没有特证 / 蓝帽子 / 医疗器械注册证，就按普通商品写。

---

## 四、虚假紧迫与引流

| 禁用 | 说明 |
|---|---|
| 最后一天、即将涨价、马上抢光 | 无真实依据即违规，平台会核查 |
| 厂家直销、一手货源 | 无证明材料不得宣称 |
| 加微信、私聊、站外下单 | 站外引流，平台限流或封禁 |
| 点击链接领红包 | 需与真实活动一致 |

---

## 五、画面层面同样受审

不只是文案：

- **使用前后对比不得过度修图**：前后光线、机位应一致，差异应来自产品效果而非后期
- **不得伪造检测报告、证书、奖牌、销量截图**
- **不得使用未经授权的品牌 Logo、明星形象、影视片段、音乐**
- **AI 生成人物**：部分平台要求在明显位置标注，投放前确认平台最新要求
- **不得出现二维码、微信号、手机号等站外引流元素**
- **儿童出镜**：需监护人授权，且不得利用儿童做功效背书

---

## 六、剧情带货的三个高危段落

| 段落 | 高危原因 | 防范措施 |
|---|---|---|
| 痛点放大 | 为卖货把处境拍得太惨，既惹恼用户又易触发审核 | 只呈现处境，不评判人；不用贬低、嘲讽台词 |
| 结果对比 | 天然接近功效承诺，且容易过度修图 | 用画面差异代替功效断言；前后机位光线一致 |
| CTA | 制造虚假紧迫、站外引流 | 紧迫感必须有真实依据；不留联系方式 |

---

## 七、特殊品类附加限制

| 品类 | 附加限制 |
|---|---|
| 食品 | 不得涉及疾病预防治疗；不得宣称保健功能（无蓝帽子） |
| 化妆品 | 不得宣称医疗作用；功效宣称需与备案一致 |
| 医疗器械 | 需广告审查批准文件，不得超出注册证范围 |
| 保健食品 | 必须标注"本品不能代替药物" |
| 母婴 / 婴幼儿食品 | 不得宣称替代母乳 |
| 服饰鞋包 | 不得宣称真皮/纯羊毛等材质而无检测依据 |
| 小家电 | 能效、安全认证需真实，不得伪造 3C |

---

## 起草阶段自查顺序

1. 全片台词搜一遍绝对化用语 → 替换
2. 结果对比段改成效断言为画面描述 → 收窄
3. 功效描述对照备案范围 → 删除超限部分
4. 痛点段检查是否丑化人群 → 改为呈现处境
5. CTA 检查是否有依据 → 补依据或删除
6. 画面元素查授权与站外引流 → 替换或删除
7. **投放前：过平台违禁词检测**（这一步不可替代）
