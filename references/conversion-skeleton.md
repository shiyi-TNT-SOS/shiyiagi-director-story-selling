# 六段转化骨架与钩子库

> 剧情带货的核心方法论。分镜之前先填骨架，骨架不实，镜头再好也不卖货。
> 时间配比可按实际时长缩放，但**六段的顺序和任务不能变**。

---

## 一、六段骨架详解

### 1. 钩子（0-3 秒）

**任务**：让观众停止划走。**禁止出现产品。**

**判定标准**：观众在第 3 秒时产生一个疑问或情绪，且这个疑问只能通过继续看来解答。

**常见失败**：
- 一开场就露产品 → 观众立刻识别为广告并划走
- 用"大家好，今天给大家推荐"开场 → 前 3 秒完播率崩塌
- 空镜头铺垫风景 → 信息量为零

### 2. 痛点放大（3-10 秒）

**任务**：让目标人群产生"这说的就是我"。

**要具体到动作**：写"她第三次把粘锅的铲子摔在灶台上"，不写"做饭很烦恼"。

**常见失败**：
- 抽象吐槽，观众无感
- 丑化目标人群（把使用者拍成笨拙/可怜）→ 既惹恼用户又容易触发审核
- 痛点与产品解法无关（比如吐槽通勤累，卖的是洗洁精）

### 3. 转折（10-18 秒）

**任务**：引入外部变量，让局面有可能改变。

**转折靠动作或一句台词，不靠旁白解释**。

类型：
- 别人一句话（闺蜜/同事/家人随口提了一句）
- 一次偶然发现（看到别人在用）
- 一次失败后的尝试（受够了，决定试试）

**常见失败**：转折生硬，像硬广插入点；或者没有转折，直接从痛点跳到产品。

### 4. 产品登场（18-32 秒）

**任务**：产品作为**解法**出现，不是作为**商品**出现。

关键区别：
- 解法：人物拿起它，开始用，问题开始被处理
- 商品：产品摆在画面中央，旁边配参数和价格

**必须拍使用过程**，不能拍静态摆拍。

**常见失败**：产品一登场就配文案念参数，广告感爆表，观众在这一秒流失。

### 5. 结果对比（32-45 秒）

**任务**：给出**肉眼可见的画面证据**。

原则：
- 对比必须是画面上能看出来的差异（油污消失、褶皱抚平、颜色变化）
- 同机位前后对比 > 不同场景拼接
- 用人物反应代替旁白夸赞（她愣了一下 / 她又摸了一遍）

**常见失败**：只说"变好了"没有画面；对比图过度修图；前后光线不一致导致不可信。

### 6. CTA（45-60 秒）

**任务**：给一个明确的下一步动作。

写法：
- 口语，一句，不超过 15 字
- 给理由（限时的、限量的、有赠品的）但必须真实
- 画面回人物表情，不以产品包装收尾

**常见失败**：念参数收尾；喊口号（"赶紧冲！"）；没有明确动作指向。

## 二、前 3 秒钩子库（8 类）

每类给一个可直接改写的句式。**至少准备 3 个备选做 A/B 测试。**

### 1. 冲突开场
```
"你能不能别再用了。"（人物对着另一人说，画面是被使用的旧物）
```
适合：替换型产品（新旧对比强）

### 2. 反常识开场
```
"这玩意儿越贵越难用，所以我换成了最便宜的。"
```
适合：性价比定位

### 3. 悬念开场
```
画面：人物盯着某处，手在抖。台词："第三次了。"
```
适合：解决反复出现的问题

### 4. 数字开场
```
"一个月，我扔了 6 个。"
```
适合：消耗品、耐用性对比

### 5. 身份代入开场
```
"如果你是每天站 8 小时的人，这条你得看完。"
```
适合：人群精准的产品

### 6. 结果前置（倒叙）
```
先给结果画面（干净/整齐/漂亮），第 2 镜倒回 3 小时前。
```
适合：效果视觉化强的品类（清洁、美妆、收纳）

### 7. 对话截取
```
从一段对话中间切入："——所以你一直都是这么洗的？"
```
适合：认知差距型（用户一直用错方法）

### 8. 失败瞬间
```
一个动作失败的特写（东西掉了、撒了、断了），不做解释。
```
适合：解决具体麻烦的产品

## 三、转折设计的三条规则

1. **转折要"轻"**：一句随口的话 > 一段长解释。越轻越可信。
2. **转折要有来源**：不能凭空"突然想到了"，要有触发物（看到、听到、被提醒）。
3. **转折后立刻进入动作**：不要停顿，不要给观众反应时间，直接切到使用。

## 四、CTA 写法

| 类型 | 句式 | 适用 |
|---|---|---|
| 需求型 | "有同样问题的，可以试试这个" | 通用，最安全 |
| 场景型 | "下次遇到这种情况，就不用忍了" | 痛点强的品类 |
| 稀缺型 | "这个价就这两天"（**必须真实**） | 有真实促销时 |
| 低门槛型 | "先试小瓶的，不合适也不亏" | 高价、需决策的产品 |
| 关系型 | "转给那个总说腰疼的人" | 礼品、家庭共用产品 |

**禁止**：不真实的紧迫感、无法兑现的承诺、无依据的销量话术。

---

## 五、评论区预判（发布前必做）

预判评论区第一条质疑，并准备应对话术。常见质疑类型：

| 质疑 | 应对方向 |
|---|---|
| "是广告吧" | 不否认，转向使用场景："是，但我用了三个月才敢发" |
| "多少钱" | 置顶回复价格 + 购买路径 |
| "不如 XX 品牌" | 不做贬低对比，说明适用场景差异 |
| "没用" | 追问具体用法，多数是用法问题 |
| "假的" | 提供可验证信息（购买记录、使用时长） |

把预判结果写进交付物，便于发布后快速响应。前 30 分钟的评论区互动直接影响推流。

## 六、骨架自检

- [ ] 六段每段都有镜头覆盖，没有跳段
- [ ] 钩子段 0-3 秒内没有出现产品
- [ ] 痛点段是具体动作，不是抽象吐槽
- [ ] 转折来自外部触发，不是凭空想到
- [ ] 产品段拍的是使用过程
- [ ] 结果段有肉眼可见的画面差异
- [ ] CTA 是一句口语，有明确动作指向
- [ ] 准备了 3 个钩子备选
- [ ] 预判了评论区第一条质疑
