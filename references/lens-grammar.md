# 镜头语法七维速查

> 分镜时每个镜头必须逐项填齐。中英文对照可直接用于拼装视频模型 prompt。

---

## 1. 景别（Shot Size）

| 中文 | 英文 | 画面范围 | 广告片典型用途 |
|---|---|---|---|
| 大远景 | Extreme Wide Shot | 环境为主，人物极小 | 开场定调、场景交代 |
| 远景 | Wide Shot | 人物全身 + 大量环境 | 建立地理/空间关系 |
| 全景 | Full Shot | 人物全身，环境少量 | 展示动作与穿着 |
| 中景 | Medium Shot | 腰部以上 | 对白、日常动作（最常用） |
| 近景 | Medium Close Up | 胸部以上 | 表情、情绪 |
| 特写 | Close Up | 头/手/物件充满画面 | 产品细节、情绪高点 |
| 大特写 | Extreme Close Up | 眼睛、材质纹理、UI | 材质工艺、视觉高潮 |

---

## 2. 角度（Camera Angle）

| 中文 | 英文 | 心理效果 | 广告片典型用途 |
|---|---|---|---|
| 平视 | Eye Level | 平等、真实 | 对白、日常 |
| 俯拍 | High Angle | 弱小、被审视 | 展示全貌、弱化主体 |
| 仰拍 | Low Angle | 强大、崇高 | 产品气场、人物权威 |
| 过肩 | Over the Shoulder | 代入对话 | 双人互动 |
| 荷兰角 | Dutch Angle | 不安、动感 | 转折、冲突段 |
| POV | Point of View | 第一人称代入 | 使用体验、沉浸展示 |

---

## 3. 运镜（Camera Movement）

| 中文 | 英文 | 说明 |
|---|---|---|
| 固定 | Static / Locked-off | 机位不动，最稳 |
| 推 | Push In / Dolly In | 机位前移，聚焦、加压 |
| 拉 | Pull Out / Dolly Out | 机位后移，释放、交代环境 |
| 摇 | Pan | 机位不动，镜头左右转 |
| 移 | Truck / Slide | 镜头横向平移 |
| 跟 | Follow / Tracking | 跟随主体移动 |
| 升降 | Crane / Boom | 垂直升降，营造体量 |
| 环绕 | Orbit / Arc | 绕主体旋转，展示立体感 |
| 手持 | Handheld | 轻微晃动，真实感 |
| 斯坦尼康 | Steadicam | 平滑跟随，长镜头 |
| 甩镜 | Whip Pan | 快速横甩，转场或强节奏 |

> 短视频优先用：固定、缓推、环绕。甩镜和手持在 AI 生成中失败率较高，慎用。

---

## 4. 光学（Optics）

格式：`焦距 + 光圈 + 景深`

| 焦距 | 视角 | 广告片用途 |
|---|---|---|
| 16-24mm | 广角 | 环境、车内、空间感（边缘会变形） |
| 35mm | 标准偏广 | 叙事主力，带环境的人物 |
| 50mm | 标准 | 最接近人眼，日常真实 |
| 85mm | 中长焦 | 人物肖像、产品主体（背景压缩） |
| 100-135mm | 长焦 | 微距、材质、虚化背景 |

| 光圈 | 景深 | 用途 |
|---|---|---|
| f/1.2 - f/1.8 | 极浅 | 单点聚焦，突出主体 |
| f/2.8 - f/4 | 浅 | 人物与产品常用 |
| f/5.6 - f/8 | 中 | 需要看清环境 |
| f/11+ | 深 | 风光、全景清晰 |

示例：`85mm f/1.8 shallow depth of field`

---

## 5. 光影（Lighting）

格式：`光源方向 + 色温 + 光比 + 时段`

**光源方向**

| 类型 | 效果 |
|---|---|
| 顺光 Front | 平、清晰、少阴影 |
| 侧光 Side | 立体、有质感 |
| 侧逆光 Back / Rim | 轮廓光，主体从背景分离（广告最常用） |
| 顶光 Top | 硬、戏剧化 |
| 底光 Under | 诡异、非常规 |

**色温**

- 2000-3200K 暖（烛光、钨丝灯）
- 4000-4500K 中性
- 5600K daylight（日光、正午）
- 6500K+ 冷（阴天、荧光）

**时段**

| 中文 | 英文 | 特征 |
|---|---|---|
| 黄金时刻 | Golden Hour | 日出后/日落前 1 小时，暖侧光长影 |
| 蓝调时刻 | Blue Hour | 日落后/日出前，冷调均匀光 |
| 正午 | Midday | 硬顶光，阴影重 |
| 阴天 | Overcast | 柔和无影，天然柔光箱 |

示例：`侧逆光 3200K 光比 1:4 黄金时刻`

---

## 6. 色彩（Color）

格式：`主色调关系 + 胶片模拟`

**常见色调关系**

| 关系 | 说明 | 适用 |
|---|---|---|
| 青橙对比 | 冷暗部 + 暖亮部 | 电影感、科技、汽车 |
| 冷暖分区 | 前景暖 / 背景冷 | 叙事、人物 |
| 单色系 | 同一色相不同明度 | 极简、高级 |
| 低饱和 | 降饱和提明度 | 日系、清新 |
| 高对比黑白 | 去色 + 强化明暗 | 质感、纪实 |

**胶片模拟**

| 名称 | 特征 |
|---|---|
| Kodak 250D | 暖、颗粒细腻、日常 |
| Kodak Vision3 500T | 冷调钨丝、夜景 |
| Fuji Eterna | 低饱和、柔和肤色 |
| Fuji Velvia | 高饱和、风光 |
| CineStill 800T | 夜景、红色光晕 |

示例：`青橙对比，Kodak 250D film look`

---

## 7. 表演与调度（Performance & Blocking）

- **写动作，不写情绪**：写"她把杯子推到桌子另一边"，不写"她表现出犹豫"
- **走位路线要具体**：从画面左后走到右前，中途在桌边停一次
- **一个镜头一个动作**：出现"同时"就该拆成两个镜头
- **无人物镜头写"无"**，但必须写明画面里有什么在动（光、烟、液体、UI）

## 中英文 prompt 拼装对照

| 维度 | 中文写法 | 英文写法 |
|---|---|---|
| 景别 | 特写 | Close-up |
| 角度 | 微俯 | slightly high angle |
| 运镜 | 固定机位 | static camera |
| 光学 | 85mm f/1.8 浅景深 | 85mm f/1.8 shallow depth of field |
| 光影 | 窗边侧逆光 5600K | window side backlight 5600K |
| 色彩 | 暖白调 Fuji Eterna | warm white tone, Fuji Eterna film look |
| 画幅时长 | 9:16，5 秒 | 9:16, 5s |
| 排除项 | 画面无叠加文字层，无慢动作 | no slow motion (文字走后期，不用 no text) |

## 带货场景的镜头选择偏好

与品牌广告不同，剧情带货的镜头选择受三重约束：**可信度优先**、**产品必须清晰**、**AI 生成可行性**。

**景别**：中景与近景为主（占 60% 以上），特写集中在产品使用环节。大远景在带货里基本无用——观众看不清，完播成本高。

**运镜**：固定与缓推为主。手持在"生活纪实型"里可用，但要控制幅度；环绕与升降留给产品登场段，用来制造"仪式感"。甩镜在带货里风险高，容易让画面显得杂乱。

**角度**：人物用平视（平等、可信），产品用微俯或 45°（展示形态与质感）。仰拍慎用——会让产品显得像在"被崇拜"，广告感过强。

**光影**：室内优先正侧光 + 补光，保证产品细节清晰。逆光虽然好看，但会让产品变成剪影，带货里要避免。结果对比段的**前后光线必须完全一致**，否则观众会怀疑是两条素材。

**色彩**：痛点段偏冷低饱和，产品登场后回暖提亮。这个冷暖转换是最廉价的情绪转折手段，且不依赖台词。

**表演**：人物动作要"不完美但真实"——手忙脚乱、随手一放、皱眉。带货视频里过度精致的动作会降低可信度。
