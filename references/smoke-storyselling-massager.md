# 行为冒烟示例（等级 2）· 颈椎按摩仪剧情带货

> 本文件是 `shiyiagi-director-story-selling` 的可执行测试：用一支 45s 颈椎按摩仪剧情带货，跑通「六段转化骨架 → 分镜表（含所属段落列）→ 逐镜提示词 → 钩子备选」，证明本 skill 能落地而非空话。

## 0. 测试场景

产品：颈舒按摩仪；卖点：3 分钟缓解落枕僵硬；人群：久坐白领；平台：抖音；时长 45s；人物 ≤2。

## 1. 第 2 步 · 六段骨架填实

| 段 | 时间 | 内容 | 失败规避 |
|---|---|---|---|
| 钩子 | 0-3s | 落枕惨叫，手扶脖子僵住 | 不露产品 |
| 痛点 | 3-10s | 演转头咔咔、敲键盘龇牙 | 演具体动作 |
| 转折 | 10-18s | 同事递来按摩仪"试试这个" | 不硬广 |
| 产品登场 | 18-32s | 戴上，使用过程特写 ≥2 | 非摆拍 |
| 结果对比 | 32-45s | 转动自如，同机位同景别 | 画面证据 |
| CTA | 45s | 口语"早买早解脱"，回人物 | 不喊口号 |

## 2. 分镜表（含所属段落列，6 镜）

| 镜 | 画面 | 所属段落 |
|---|---|---|
| 1 | 主角扶脖惨叫僵住 | 钩子 |
| 2 | 转头咔咔、敲键盘龇牙 | 痛点 |
| 3 | 同事递按摩仪 | 转折 |
| 4 | 戴上，颈部按摩特写 | 产品登场 |
| 5 | 转动脖子自如（同机位） | 结果对比 |
| 6 | 主角对镜笑，挂车 | CTA |

## 3. 钩子 3 备选

1. 落枕惨叫 + 手僵在半空
2. 对镜子扭头"咔"一声定住
3. 凌晨三点被脖痛醒，翻不了身

## 4. 逐镜提示词（带货专用）

**镜 1（钩子）**
> [年轻白领扶脖僵在椅上，惨叫] + [中景·固定机位] + [微晃手持感] + [办公室顶光，冷白] + [低饱和] + [9:16·生成 4s] + [惨叫 + 键盘声]

**镜 4（产品登场）**
> [主角戴上颈舒按摩仪，颈部脉冲特写，肌肉松弛] + [近景·固定] + [缓慢推] + [暖光打产品] + [暖调] + [9:16·生成 5s] + [低频脉冲音效 + 环境静默]

## 5. 自检（关键项）

- [x] 六段每段填实，无跳段
- [x] 钩子不露产品，3 备选
- [x] 产品特写 ≥2（镜4 使用过程）
- [x] 结果对比同机位/同景别
- [x] 人物 ≤2；手部动作降级（戴机非精细手）
- [x] CTA 口语，回人物

## 6. 结论

产出骨架 + 6 镜分镜（含段落列）+ 钩子 3 备选 + 2 条提示词，自检通过。反向对照：若只给纯导演提示词，会产出漂亮但不卖货的镜头。
