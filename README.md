# director-story-selling · 剧情带货导演提示词

> 把卖点藏进故事里，而不是直接念卖点。
> 一个给 AI 视频生成用的「导演提示词」封装 —— 输入卖点和人群，输出**不跑偏、能卖货**的分镜。

作者：**柳十一**（十一AGI认知圈） · License: MIT · v1.0.0

---

## 它解决什么问题

剧情带货最容易翻车的地方不是画面不好看，而是 —— **好看但不卖货**。

你直接给 AI 一段纯导演提示词，它会给你产出很漂亮的镜头。但结果通常是：

- 没有钩子，前 3 秒就把人劝退
- 没有转折，全程平铺直叙
- 产品忘了露脸，或者只在最后飘一下
- 结尾没有 CTA，观众看完觉得"拍得不错"，然后划走

**这个 skill 在通用导演四层结构之上，强制叠加一层「转化骨架」。** 导演只能在骨架内发挥 —— 这不是限制创意，是防止 AI 跑偏。

---

## 核心方法

### 1. 六段转化骨架（硬约束）

```
钩子          痛点放大        转折           产品登场        结果对比        CTA
0-3s          3-10s          10-18s         18-32s         32-45s         45-60s
┌────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌────────┐
│ 冲突/悬念│ → │ 演一遍踩坑│ → │ 外部变量 │ → │ 作为"解法"│ → │ 肉眼可见 │ → │ 口语引导│
│ 不露产品 │   │ 具体到动作│   │ 一句话/偶然│  │ 不是"商品"│   │ 的画面差异│   │ 回人物表情│
└────────┘   └─────────┘   └─────────┘   └─────────┘   └─────────┘   └────────┘
```

时间配比可按实际时长缩放，但**六段的顺序和任务不能变**。

### 2. 三条数字约束（写在【边界】里）

| 约束 | 值 | 为什么 |
|---|---|---|
| 产品首次露出 | ≤ 第 18 秒 | 太早 = 广告，太晚 = 没记住 |
| 产品特写 | ≥ 2 个，且必须是**使用过程** | 静态摆拍 = 零转化 |
| 全片人物 | ≤ 2 人 | 降低 AI 生成崩坏概率 |

### 3. 四要素提示词结构

每一次产出都包含完整的四个块：

**【目标】** 要什么 · **【素材】** 有什么 · **【规格】** 什么规格 · **【边界】** 不能越的线

## 快速上手

**输入（brief）**

> 产品：某款不粘锅
> 卖点：煎鱼不破皮、少油也不粘
> 人群：25-35 岁、刚开始自己做饭、已经被粘锅折磨过的上班族
> 平台：抖音 · 时长 45s

**输出（节选）**

| # | 所属段落 | 时长 | 景别 | 画面 | 台词/音效 |
|---|---|---|---|---|---|
| 1 | 钩子 | 0-3s | 特写 | 铲子刮锅底的刺耳声，鱼皮整片留在锅上 | 音效：金属刮擦声（无台词） |
| 2 | 痛点放大 | 3-10s | 中景 | 她第三次把粘锅的铲子摔在灶台上，冰箱上贴着没吃完的外卖单 | "第几次了……" |
| 3 | 转折 | 10-18s | 近景 | 合租室友端着自己的锅过来，随口一句 | "你换个锅试试？" |
| 4 | 产品登场 | 18-32s | 特写 | 少油、鱼下锅、铲子一推整条滑出 | 音效：油花轻响 |
| … | … | … | … | … | … |

> 表格后必须附三块：**一句话核心卖点** / **前 3 秒钩子 3 个备选** / **评论区首条质疑与应对话术**。
> 「所属段落」列是本 skill 特有的 —— 它是检查每个镜头是否承担转化任务的依据。

## 使用前请确认

- 本 skill 只做**创意与分镜交付**，不负责拍摄、剪辑、发布、数据复盘。
- 输入必须是"已确定的卖点与目标人群"；选品、爆款拆解、投放策略请走 `ecommerce-video-workbench`。
- 合规部分以**投放平台最新规则与后台违禁词检测**为最终依据，`compliance.md` 只是起草期自查清单。
- 真实投放后，把高完播的钩子类型和转折方式沉淀回 `references/conversion-skeleton.md`，减少每次重复推理。
